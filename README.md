# Система бронювання столиків у ресторані 🍽️

## Опис проєкту
Вебдодаток для автоматизації процесу резервування місць у закладі харчування «ВЕЛЮР». Проєкт реалізує клієнт-серверну архітектуру та дозволяє користувачам переглядати вільні столики і здійснювати преміум-бронювання, а адміністратору — керувати записами та інформацією про заклад. Проєкт розробляється в рамках університетської практики.

## Основний функціонал

**Для клієнта (Інтерфейс користувача):**
* **Інтерактивне меню (Signature Menu):** Перегляд позицій меню ресторану, розбитих за категоріями (Сніданки, Обіди, Вечері, Десерти, Напої) з актуальними цінами.
* **Інформаційні блоки:** Розділ «Наша Історія» про концепцію закладу та футер із контактними даними (телефон, E-mail, адреса).
* **Форма преміум-бронювання:** Можливість вибору ID столика, дати, часу, кількості гостей та введення контактних даних (ім'я, телефон).
* **Візуалізація статусів:** Інтутивно зрозуміле відображення стану столиків (Вільний / Зайнятий) за допомогою кольорових індикаторів.

**Для адміністратора:**
* Контроль завантаженості залу в реальному часі.
* Керування базою даних бронювань (підтвердження, скасування).

## Стек технологій
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
* **Backend:** Node.js
* **База даних:** SQLite (модуль `sqlite3`)
* **Інструменти роботи з БД:** DB Browser for SQLite

## Структура репозиторію
* `frontend/` — клієнтська частина користувацького інтерфейсу (HTML, CSS, JS, зображення).
* `backend/` — серверна логіка та обробка API запитів.
* `database.js` — скрипт конфігурації та підключення до бази даних.
* `.gitignore` — перелік файлів і директорій, що не відстежуються системою Git.
* `package.json` — конфігураційний файл проєкту та його залежностей.
