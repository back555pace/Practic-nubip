# Система бронювання столиків у ресторані

## Опис проєкту
Вебдодаток для автоматизації процесу резервування місць у закладі харчування. Проєкт реалізує клієнт-серверну архітектуру та дозволяє користувачам переглядати вільні столики і здійснювати бронювання, а адміністратору — керувати записами та інформацією про заклад.

## Стек технологій
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
* **Backend:** Node.js
* **База даних:** SQLite (модуль `sqlite3`)
* **Інструменти роботи з БД:** DB Browser for SQLite

## Структура репозиторію
* `frontend/` — клієнтська частина користувацького інтерфейсу (HTML, CSS, JS).
* `backend/` — серверна логіка та обробка API запитів.
* `database.js` — скрипт конфігурації та підключення до бази даних.
* `.gitignore` — перелік файлів і директорій, що не відстежуються системою контролю версій (включаючи `node_modules/`).
